# Medlix Hospital - Official Web Portal

Modern, responsive web application for **Medlix Super Specialty Hospitals**, built with **Next.js 14 (App Router)**, **TypeScript**, and **Tailwind CSS**.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14.2.3](https://nextjs.org/) (App Router, Server & Client Components)
- **Language**: [TypeScript 5](https://www.typescriptlang.org/) (Full static type safety)
- **Styling**: [Tailwind CSS 3.4.1](https://tailwindcss.com/) with PostCSS & custom brand animations
- **Icons**: [Lucide React](https://lucide.dev/)
- **Carousels & Motion**: [Swiper 11](https://swiperjs.com/) & [Framer Motion](https://www.framer.com/motion/)

---

## 🏥 Features & Preserved Architecture

- **100% Faithful Content**: Retains all original hospital branches, specialties, emergency contacts, TPA panels, and clinical services.
- **Brand Consistency**: Deep Navy (`#0A2540`), Signature Medical Teal (`#0A5F6B`), and Aqua Accents (`#14B8A6`).
- **Fully Responsive**: Optimized for Mobile, Tablet, and Desktop screens with zero horizontal overflow.
- **Interactive Modules**:
  - Live 24x7 Emergency Contact Bars
  - OPD Doctor Appointment Booking Modal & Form
  - Clinical Specialties Carousel
  - Hospital Branch Directory across NCR (8 Centers)
  - Cashless Insurance & TPA Empanelment Portal

---

## 🚀 Getting Started

First, install dependencies (if not already installed):

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

To generate a production build:

```bash
npm run build
npm start
```
